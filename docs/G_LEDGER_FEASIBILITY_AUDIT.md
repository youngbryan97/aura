# G-ledger feasibility audit

This audit distinguishes protocol impossibility from an unsolved engineering
problem. It supplements the semantic correctness contract and does not reduce
any acceptance standard. No absence of a known impossibility theorem establishes
that the current architecture will achieve broad or frontier reasoning gains.

## Required distinctions

1. Information: does the permitted input contain enough information to determine
   the requested answer? Identical observations with incompatible valid targets
   require clarification or a richer observation contract, not more training.
2. Representation: can the permitted program grammar express a correct answer?
   A witness proves existence for that case; incomplete search proves no absence.
3. Feasibility: do typing, connectivity, grounding and ownership constraints
   admit that witness? Test the exact runtime constraints, not a looser executor.
4. Selection capacity: can shared parameters rank the required decisions together?
   Affine certificates apply only to the declared affine score class. Per-case
   fitting and local nonlinear approximations do not prove shared capacity.
5. Learnability and resources: can training recover useful parameters and can
   runtime search reach the answer within measured resources? These require
   experiments even when representation and constraints are sufficient.
6. Measurement: can a genuinely correct public answer pass the grader? Check
   valid notation, units, alternatives, partial definedness and public/private
   channels using independent positive and negative controls.

  boundaries and labels lets the unchanged argument machinery solve 23; one
  division binding still fails. See the boundary intervention receipt. This is
  downstream feasibility evidence, not a proof of 500/500 attainable learning.
- G04/G07: fresh transfer needs disjoint tasks and explicit information/grammar
  coverage. A shared primitive vocabulary is not permission to reuse exposed
  examples. Power must match effect size, paired discordance and clustering.
- G05/G06: historical exact-wire notation rejection and missing public operation
  definitions show real protocol defects. Versioned semantic grading and complete
  task information must precede new comparisons. Correct controls are not failures
  to repair; gain may be absent on tasks the baseline already solves.
- G08: independent verification must accept witnessed valid outputs and reject
  wrong ones without reading the treatment identity. Unknown observations remain
  unknown, not passes. Full denominators remain fixed prospectively.
- G09: universal expressibility does not provide missing empirical information,
  a correct interpretation, or efficient search. Broad gain is a testable target,
  not a consequence of owning the code or having an interpreter.
- G10: architectural geometry and exact state preservation can be tested before
  training. Successful fusion must preserve measured behavior; sharing dimensions
  or completing serialization is insufficient. No universal no-regression claim
  follows from finite canaries.
- G12: a fair frontier comparison is feasible to design; winning it is an open
  empirical goal. Missing baseline access or incomparable tool budgets must be
  resolved or disclosed, never replaced with an invented equivalence claim.

## Protocol changes

For every artificial blocker: preserve the old protocol and result, publish the
counterexample demonstrating the defect, version the corrected contract, run
positive and negative grader controls, and rerun all affected comparison arms.
Do not selectively regrade treatment successes. A narrower justified claim may
be reported, but it does not close the original broader obligation.
