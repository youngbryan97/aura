## Computational subjecthood

The November ISC preprint reports 24 of 24 operational checks passing on
the confirmatory seed. Separate experiments measured the carrier, the
structure of recalled content, and a model's reports under controlled
changes in valence. The preprint documents follow-up failures and the
assumptions behind its argument about experience.
[Study introduction](ISC_EXPLAINED.md) · [Preprint](https://doi.org/10.5281/zenodo.24075466) · [Results](ISC_STATUS.md)

Use the replication kit for the 22-line substrate campaign or the full run
data to inspect the recorded experiments. Use the pinned source from the
paper if reproducing its numbers.

## Review or repeat a result

Use the original commands, recorded inputs, and controls. Report new results
beside the original, including failed and unreadable cases. Use a separate
state and log directory for any rerun. Reserve a model and a time window
before running an experiment that needs one.
[Testing guide](../TESTING.md) · [Reviewer packet](REVIEWER_PACKET.md)
