# Scoped pragmatic evidence inside the existing language substrate

`UsageEvent` now retains bounded, source-attributed relations alongside
lexical use, delivery cues, and independently identified referents. A relation
distinguishes a claim, an observation, and explicit withholding. Its subject,
predicate, scope, polarity, and exclusivity determine whether a second
relation is actually comparable. Different values on a nonexclusive relation
or in different scopes are not called contradictions.

`compare_pragmatic_context` measures alignment and incongruity across
independent sources, including multiple sources in one bundled event and
later observations admitted by an explicit time cutoff. It never infers
whether an incongruity was a mistake, joke, fictional statement, deliberate
misdirection, changed circumstance, or incomplete evidence. Missing evidence
is not reclassified as withholding; withholding must be an attributed event.

`MeaningFeedback` can carry an attributed communicative mode: literal,
indirect, metaphor, allusion, joke, fiction, mistake, or deception. Its
existing support/refutation and source controls still apply. The existing
contrastive contextual scorer ranks combined sense/mode readings from prior
support, with held-out sources and future feedback excluded. A measured
relation fit enters that same scorer as an optional feature, not as a rule
mapping mismatch to any mode. Independently identified, unspoken referents
remain possible stand-ins, not asserted intentions. The same semantic service
persists structured usage and feedback through runtime intake, and rejects
sensitive values using Aura's shared redaction patterns.

This is a developmental mechanism with no serving authority. Ordinary chat
intake observes bounded lexical use but does not yet supply source-verified
proposition/action relations or attributed intention feedback. The system
therefore cannot claim it detects hidden meaning in arbitrary conversation.
It may return unresolved when exposure or discriminating evidence is absent.
Natural-language relation acquisition, independent held-out evaluation across
communities/settings, and a non-regressing serving admission decision remain
open. None of this closes G03 or proves broad reasoning transfer.
