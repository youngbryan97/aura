## Adopted in the opt-in path

- A source occurrence keeps its identity when two public values happen to
  match. `MeaningHypothesis` already carried that identity. The new
  `compare_source_bound_meanings` asks whether alternate compiled programs
  differ on typed counterfactual inputs. It delegates exact execution and
  structural equivalence to `semantic_graph_counterexamples`; finite probes
  without a witness return `unknown`.
- `select_source_bound_portfolio` sends the same immutable source-bank
  alternatives through the existing execution portfolio. Its inquiry planner
  predicts which input would distinguish them, but it does not manufacture the
  observed answer. The portfolio can revise its selection only after an
  independent result with an origin and reference passes replay checks.
- The test with equal current values and reversed subtraction roles stays
  unresolved without a probe and becomes distinguishable under an
  intervention. This is a test of executable consequences, not a test that
  either reading matches the source sentence.
- Portfolio reconciliation replays the proposed programs on the selected
  input before accepting feedback. A measured result can change the selected
  program while preserving source and proposal receipts; it cannot certify
  every unseen input or a subjective feeling of certainty.

## Not adopted as fact

The exports alternately call a hub-and-spoke architecture unique, a sharp
uncertainty drop a necessary phase transition, and global broadcast or
recurrent integration identical to felt experience. None follows from the
provided equations. A two-model posterior can change smoothly; a model
switch need not have a divergent precision. A computational signal can be
wrong, including a false insight. Different implementations can support the
same tested input-output relation. Neither source-bound execution nor a
broadcast measures phenomenality. These remain research hypotheses, without
serving or scientific-claim authority.

One export argues that temporal integration requires an attractor. A
stateful process can integrate observations without converging to a fixed
point, so that claimed necessity was not adopted. The other explicitly
labels its phenomenal bridge an unproven axiom. Its useful experimental rule
is to compare rival mechanisms on matched tasks with predeclared lesions;
the existing G ledger already requires that discipline.
