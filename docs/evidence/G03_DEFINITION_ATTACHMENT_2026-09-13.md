## Mechanism

Arithmetic diagnosis found correctly selected argument phrases in the correct
slots, followed by reversed register links. A fronted literal's name could be
to its right while the candidate search admitted only left envelopes. The
corpus now optionally annotates that existing name without changing any task
text, tokens or executable meaning.

A local bidirectional search was insufficient and regressed composition. The
learned attachment path keeps legacy local hypotheses and adds definitions
selected from the shared pointer bank. Its evidence enters the existing graph
optimizer once per used definition, never once per repeated reference and
never for an unused positive hypothesis. Exhaustive small-graph comparisons
test the objective against enumeration.

The first objective marked every non-target phrase negative for an anchor.
That conflated definition identification with ownership. The second objective
compares the annotated definition against possible register owners, without
labeling alternate phrases as incorrect names. Runtime scores are normalized
over owners. This repairs the supervision distinction, but the measurements
above do not establish sufficient transfer. Both objectives remain versioned
and replayable; neither changes the serving activation.
