# Observed inquiry feedback reaches program selection

The semantic portfolio can reconcile an independently supplied probe result.
It checks that the inquiry names the current programs, replays those programs
on the probe through the checked floor, and feeds agreement into the existing
necessary-condition selector. A compatible incumbent remains selected. An
incompatible incumbent can yield to a compatible executable alternative. If
all candidates disagree, reconciliation returns unresolved and retains the
original proposals.

Agreement packets use the shared evidence algebra and carry the observation's
origin and reference. Re-delivering the same observation does not add evidence
mass. Packet subjects bind the probe and program, preventing accidental fusion
of evidence about different claims. Serialized pending inquiries now include a
content digest covering predictions as well as probe and program identities.
Replay before selection remains necessary: a digest is not proof of execution.

Reconciliation accepts a history of independent observations. A candidate
must agree with every observed probe; reversing delivery order or repeating a
receipt does not change the selected program. Reusing one receipt identity for
conflicting outcomes is rejected. A later observation cannot restore a
candidate refuted by an earlier one.

The observation is an input supplied by the caller, not a result invented by
the model or an evaluation label read by the selector. The caller must obtain
it independently and establish that the probe applies to the task. Agreement
on a probe does not establish correctness elsewhere. Desktop observation
delivery and broad held-out qualification remain open.
