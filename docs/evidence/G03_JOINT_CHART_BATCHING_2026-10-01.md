## Explicit Batched Replay

`tools/semantic_grounded_batched_chart.py` supplies an opt-in replay variant.
It vmaps the **unchanged fitted pointer**, retaining a separate complete
graph workspace for every candidate-conditioned mention and definition.
There is no substitute scoring formula, candidate truncation, new training
or changed checkpoint. Context admission, public operation/slot queries,
graph adjacency, nuisance projection, baseline terms, global SSA constraints,
best distinct graph and ambiguity handling remain present.

Conditioned alternatives are evaluated in batches of at most sixteen. Public
source-span means are cached within one source-bound solver; unrelated
requests cannot share that cache. Complete evidence is checked once per
chart, conditioned arrays once per batch, and a batch's requested scores are
read together. Every alternative still receives its own changed mention and,
where present, candidate definition. The selected graph and all measured
edge evidence are retained.

This is a declared execution variant. Its file hash, batch bound and policy
are recorded in the evaluation plan and each native decode receipt. The
original training implementation and fit verifier are unchanged; the fit is
not silently reauthorized under modified training code. Vectorization can
change floating-point reduction order, so finite fixtures compare scores
with an explicit tolerance rather than claim universal bit identity.

Focused checks passed 51 tests in 35.48 seconds. They compare all individual
and batched scores across 0/1/2/4 graph rounds, alternative mentions and
definitions, nuisance projection and a batch boundary. Complete chart
arguments, score, margin and edge receipts match the individual path. Tiny
native and quantized hybrid replay use the same selected weights and return
the same program or refusal. Inadmissible identities and nonfinite states
are rejected.

These fixtures do not show that the real checkpoint interprets language
correctly. A bounded real replay must next measure whether the execution
variant finishes, what graph it selects, and whether both controls' correct
answers are retained. G03 and later scientific gates remain open.

## Factored Replay And Certified Reduction

Execution version two separates the pointer's independent learned depth
pooling and projection from its graph refinement. Source-local immutable
observations share those independent encodings. Each conditioned alternative
still gets its own complete graph messages and original role/product
interactions. A reduced-width view calls the original relation function with
identity projections and one already-pooled depth; message/update, role
query and scoring weights are unchanged references to the verified fit.
The helper file hash is part of the declared execution contract.

After every original alternative is scored, a mention is removable only if
another choice in the same slot has the same register and definition,
no smaller score, and a subset of its occupied tokens. Replacement preserves
register use, definition consistency, dependencies, graph exclusions and
token exclusivity. The solver keeps a witness for every removed realization.
No register graph is removed by this rule. The original score-based ambiguity
tolerance is restored after reduction; fewer redundant options cannot turn
an old ambiguous graph into a newly admitted answer.
