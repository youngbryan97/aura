# Learned procedure reuse measurement

The new evaluator sends a frozen transducer's output to the existing common
procedure registry and executes it through the universal floor on new public
input values. It does not pass the source target or expected answer to either
consumer. Its registry is local to evaluation and cannot publish serving
procedures.

Two outcomes are counted separately: whether registry execution preserves the
selected program, and whether that result matches the requested computation.
A wrong interpretation can pass the first and fail the second. Refused parses
remain in the example denominator. Finite probes do not become equivalence
proofs; only the existing supported structural or polynomial proofs count as
proved equivalence.

The command `tools/evaluate_semantic_procedure_reuse.py` admits the same exact
source-bank manifests and split identities as the refit command. It writes an
immutable receipt with each execution, refusal, failed probe and model identity.

Checks: 22 focused tests pass, including the common registry, parameterized
floor execution, wrong-interpretation controls, and one fitted synthetic
transducer feeding the registry. These tests do not constitute a full 27B
cohort result, new-wording transfer, S06 closure, or broad reasoning gain.
