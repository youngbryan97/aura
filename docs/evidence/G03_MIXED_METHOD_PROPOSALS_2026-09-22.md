# Mixed semantic proposals and durable feedback

The existing portfolio now optionally recombines complete programs from
independent methods. It retains every original proposal and the incumbent,
checks derived programs against the shared floor's type signatures and graph
structure, binds each derived program to its instruction sources, and reports
when its finite search did not exhaust the declared combinations. New proposals
have no correctness authority. Counterfactual comparison reuses one checked
execution cache across the portfolio instead of repeating the same floor work
for each pair.

An inquiry's caller-supplied observed result can be retained through the existing
state gateway. The gateway's snapshot now reads durable entries after process
reopening; previously it enumerated only that process's cache. Reopened
portfolios replay all matching observations. Two outcomes with the same origin
and reference cannot silently replace one another or select a winner.
New inquiries also bind the source-request identity, so the same programs and
probe cannot carry feedback across different utterances. Historical unbound
inquiry records remain readable but cannot be reconciled into a source-bound
portfolio. The caller's origin string is not authentication of an independent
measurement; a trusted live feedback ingress has not been connected.
This is local evidence reconciliation, not a deployed conversational feedback
loop or proof that an observed example determines every future input.

then graded against the exposed labels. It **proved one additional equivalent
program among the 14 coverage misses**. All 23 failure rows exhausted this
limited crossover search under an allowance of eight new candidates and 256
examined combinations. It does not repair the other 13 coverage misses or the
nine selection misses. The answer-blind selector and its 477/500 result did not
change. This is evidence for keeping a mixed portfolio, not a promotable
candidate or evidence of broad transfer.
