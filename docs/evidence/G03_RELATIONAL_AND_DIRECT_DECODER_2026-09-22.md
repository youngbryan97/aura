# Relational evidence and direct decoding

These are development components, not a serving promotion or G03 closure.

The relational adapter encodes structural comparison, interpretation revision,
perspective versus observed truth, and evidence-backed principle candidates.
Contradictions call the existing concept-formation prediction-error interface;
beliefs use the existing AgentModel. It creates no interpreter or language
vocabulary. Goal order is retained: reversing a relation in a goal must not
silently preserve its meaning. Replayed evidence does not increase support,
and missing verdicts cannot become positive evidence.

The adapter is not wired into live selection. Its consolidation label is an
evidence threshold, not proof of universal truth. Concept-engine integration
has a contract test; live causal benefit remains unmeasured. Semantic goal
equivalence, persistent retention, and learned abstraction discovery remain
outside this component's tested claims.

The direct whole-program decoder uses existing typed primitives and grounded
input spans. The retained scaled source-fold run fits 508/508 training cases
and solves 187/256 held-out cases. This is insufficient for promotion. Frozen
grounding had seen the source fold, so the result is not end-to-end unseen
generalization. Receipt:
`~/.aura/rlc-evidence/semantic-direct-program-scaled-fold0-20260921/report.json`.

The combined relational and direct-decoder unit suites passed 27 tests on
2026-09-22. Unit tests do not establish broad transfer or frontier performance.
