## Preserved Function

graph workspace with every role and every referent. Its bounded message
rounds update all of those nodes. The final feature map then independently
constructs sixteen pointwise product/difference blocks for each role and
candidate pair, applies SiLU and the fitted readout. Those final edge
features do not feed any further message round.

The caller reads one edge from each conditioned workspace. Version four
therefore gathers that edge after the complete node updates and before the
pointwise feature map. If there are R roles and C referents, it constructs
one final edge feature vector instead of R*C vectors per alternative.
Gathering commutes with those pointwise blocks, SiLU and the final linear
readout. It cannot change another node, omit a graph message, change the
candidate pool or authorize a different role. Depth pooling, nuisance
projection and the fitted observation matrices remain unchanged.
