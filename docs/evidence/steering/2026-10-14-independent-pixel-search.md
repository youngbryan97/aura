## Implemented chain

1. `CanvasFrames` brackets the actual canvas-read request. Its immutable
   receipt retains the page-generated canvas owner, extent generation and
   capture sequence through decoding and serialization. Missing metadata
   leaves the capture bound unknown.
2. A bounded experiment fixes randomized input assignments before looking
   at pixels. Each acknowledged press owns distinct frozen before/after
   RGB bytes. Reused captures, changed surfaces, overlapping inputs and
   unmatched exposure windows retire the experiment without omitting trials.
3. The collector uses the actor's existing input clocks and physical key
   ownership. Other inputs invalidate the interval. Cancellation releases
   only the retained acknowledged owner. Missing acknowledgements remain
   explicit unresolved dispatches; they do not become successful releases.
4. Original sparse RGB correspondence measures translation and local
   rotation before any object exists. Forward/reverse patch checks retain
   current support. A distributed translation reference is optional;
   unreferenced screen motion remains labelled as such. Moving angular
   layers are separated from still background, and an angular cell requires
   its own retained moving material rather than borrowing a nearby turn.
5. Whole-press permutations test one fixed discovery cohort. Separate
   confirmation presses test the selected pattern without choosing another
   region. Missing feature support stays unavailable. A result supplies
   search priority only.
6. An exact-frame hint crosses the actual observation thread and child IPC
   to source point sampling. It reserves part of existing point capacity
   while keeping quiet reference points. The sampler's immutable receipt
   counts retained and fresh points after actual allocation.
7. The ordinary actor can perform one finite search after its ordinary
   unresolved body trials and their neutral phase. It uses current body
   controls, the normal capture reader and the same receipt-backed hands.
   A retained-point hint permits new ordinary trials. Existing object
   continuity and control-identification thresholds remain in force.

There are no character names, game URLs, game numbers, shader uniform names
or per-game control policies in this implementation. It loads no tracking
model and asks no language model to select the measured region.
