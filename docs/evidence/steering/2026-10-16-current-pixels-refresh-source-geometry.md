# Current pixels refresh source geometry

The ordinary observation path can now remeasure a registered source frame
after its global named marks disappear. On the existing 100-frame case-18
recording, the final run supplied the composite reference's origin on 42
captures through fresh or continuing material. The earlier material-only
path supplied it on eight. This is a perception result. No game input,
native-app request, controlled-body proof or gameplay win was measured.

## Fresh measurement

The background reference worker offers captured pose proposals alongside
its existing object-bound and named-material bindings. Each proposal keeps
the registered source, reference bytes, original captured RGB receipt and
revision. A pose proposes where to look. It supplies no continuing object
identity, task role or input authority.

`near_reference_appearances` searches a bounded region near each proposed
pose. Its first version started the patch solver directly at that pose;
a three-pixel synthetic displacement exposed a local minimum. The corrected
version uses masked colour-cost peaks for coarse placement, then the
ordinary bidirectional patch and redundant rigid/affine fit. At least six
current correspondences must qualify. Patch, reverse-check and material
thresholds remain unchanged. Four proposed poses and eight returned
appearances bound each call. Other, unsearched copies remain possible.

Normal `PlayObservation` runs the fresh measurement on its observation
worker after the ordinary eyes consume that picture. The source geometry
must name that exact RGB receipt and sampling grid. It can qualify with no
canonical object and no named global point. This creates a geometry-only
channel, `fresh_source_reference_frames`; it does not change body attribution
or allow a reference name to select a controlled body.

The source origin uses the independent export calibration and actual
per-axis image sampling. Its error estimate includes calibration, pixel
resolution, correspondence spread and the origin's lever arm. Origins whose
error exceeds one working pixel are refused. A distant origin can fail
even when the visible reference matches. A box centre is never substituted.

Agreeing source-origin hypotheses are enclosed by one error circle whose
radius covers each estimate and its error. Their support count is the
minimum, not the sum. `hypotheses` records alternatives; it does not count
physical objects. Disagreeing origins remain separate candidates.

## Scope and optional work

A new source scope clears old search proposals. Future captures cannot seed
earlier ones, and publication checks current source membership again. A
missing reference stays unavailable. When an old search bank exceeds
capacity, a bounded fresh proposal can retire those old search hints with
an explicit status. This fixes a capacity latch found in the first ordinary
run. More than four fresh proposed copies still refuses warm measurement;
it cannot silently turn them into a unique candidate.

Only one registered reference receives fresh work per frame. Previously
published source geometry supplies priority hints so the worker can spend
more time where another observation channel has not supplied geometry.
Every fourth slot audits the full reference set fairly. These hints affect
work allocation only. Old points cannot become current evidence through
that route. Broad discovery continues on the existing optional worker.

The fresh cache belongs to the private observation worker. Reference pixels
are not copied into the public observation mirror or resent through the
separate-eye process on each frame. Closing the owner drops the cache;
running work keeps its own data until completion. A blocked fresh-measurement
test verifies that a normal physical-control lease releases through the
hands protocol before that measurement finishes. This is protocol evidence,
not native keyboard-delivery evidence.
