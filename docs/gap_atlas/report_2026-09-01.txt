SCOPE AND EPISTEMIC RULES
- This report compares architecture, cognitive primitives, scientific maturity, engineering practice,
  empirical evidence, scaling, and end-state. It does not equate software complexity with intelligence.
- Aura judgments are pinned to the frozen commit above. Later commits are outside scope.
- A rival is marked ahead only where a concrete property, implementation pattern, evidence program,
  or demonstrated capability is stronger. If Aura already has the primitive, the gap is described as
  integration/evidence/scale/theory rather than pretending it is absent.
- For proprietary modern systems, only public claims and demonstrations are considered; undocumented
  internals are not assumed.
- Historical OpenCog components such as classic PLN/pattern-miner work are not automatically treated
  as current superiority. The report imports useful properties, not historical branding.
- Every proposed upgrade includes a proof-of-closure test. A gap is not closed because code exists;
  it is closed only when the intended causal/capability property is demonstrated.

Important verified current-source corrections:
- ACT-R-like activation is already implemented in core/cognition/actr_activation.py. Its source explicitly
  rejects ACT-R latency transfer to Aura ranked-scan recall after measuring essentially zero relationship;
  this is a calibration/memory-architecture gap, not an equation-implementation gap.
- Soar-inspired impasses, exact chunks, utility accounting, and a guarded generalized-rule learner already
  exist. The deeper Soar gap is automatic full substates and dependency-backtraced architecture-wide compilation.
- Aura already has a clean-room typed metagraph, PLN-like truth values, ECAN-like attention, and bounded
  MeTTa-style rewriting. Hyperon therefore leads on meta-language depth/runtime/ecosystem/scale, not graph existence.
- Aura has a real trainable VRNN world model and a real perceive-act-observe screen-pursuit loop, but both
  remain tiny in data/environment scope compared with modern world-model and embodied-agent research.
- The RLC path now compositionally executes supplied typed workflows and can causally feed a computed state
  into resident decode. It does not yet autonomously derive the workflow or establish hidden-state co-reasoning.

GAP TYPE KEY
- ABSENT: Aura has no sufficiently close mechanism at the frozen commit.
- ABSENT/PARTIAL: Some local analogues exist, but no sufficient general mechanism was found.
- ARCHITECTURE GAP: The rival uses a materially different architecture that solves a problem Aura still has.
- CAPABILITY GAP: The rival currently demonstrates stronger capability on this axis.
- CAPABILITY/EVIDENCE GAP: The capability is underdeveloped and not broadly demonstrated.
- CAPABILITY/SAFETY GAP: Closing the capability gap requires a new safety/governance mechanism too.
- CAPABILITY/SCALE GAP: The gap is both raw capability and the scale supporting it.
- ENGINEERING GAP: The rival has stronger implementation/runtime/tooling infrastructure on this axis.
- EVIDENCE GAP: The closest Aura mechanism exists, but the rival has substantially stronger validation.
- EVIDENCE/STRUCTURE GAP: Both the structural formalization and its validation are behind.
- INTEGRATION GAP: Aura has pieces, but not a canonical architecture-wide mechanism.
- INTEGRATION/THEORY GAP: Aura has multiple mechanisms but lacks a single theory/contract connecting them.
- PARTIAL: Aura has a meaningful analogue, but the rival has stronger semantics, integration, evidence, or generality.
- PARTIAL/ABSENT: A narrow analogue exists; the general form is absent.
- PROCESS GAP: The rival/research program has a stronger scientific or engineering practice.
- PROCESS/SCALE GAP: The process exists in smaller form but not at comparable organizational/evaluation scale.
- SCALE GAP: The main difference is data/model/environment/engineering scale rather than the basic idea.
- SCALE/EVIDENCE GAP: Scale and external evidence both substantially trail.
- SCALE/INTEGRATION GAP: The idea exists locally but not at the rival scale or architecture-wide.
- SCIENCE GAP: The deficit is primarily falsifiability, calibration, causal attribution, or external validation.
- THEORY GAP: The rival has a more coherent or parsimonious theory for this property.
- THEORY/EVIDENCE GAP: Both theoretical coherence and empirical discrimination are behind.

EXECUTIVE SYNTHESIS
The main finding is not that Aura lacks the canonical ingredients of cognitive architecture. In many cases
it already contains a serious analogue. The remaining gaps are increasingly second-order:
  1. architecture-wide semantics instead of local mechanisms;
  2. automatic compilation/proceduralization from lived causal traces;
  3. a common evidence/resource/procedure language across subsystems;
  4. implicit <-> explicit <-> neural conversion and credit assignment;
  5. large-scale visual/world experience and held-out environment transfer;
  6. scientific calibration, matched-compute ablation, preregistration, and independent replication;
  7. theoretical compression: fewer universal mechanisms that explain more of the organism;
  8. autonomous extension of operator semantics, not only vocabulary inside a fixed meta-language.

The practical implication is severe: adding more cognitive organs is no longer the highest-value strategy.
The path to exceeding these systems is to make Aura more unified, more developmental, more experimentally
falsifiable, and much more broadly grounded in varied environments.

SYSTEM: ACT-R
####################################################################################################
ACT-R is ahead mainly in empirical cognitive science: calibrated timing, human-data fitting, and architecture-wide procedural skill acquisition. Aura already has an unusually disciplined ACT-R-inspired activation module, so importing equations alone would add little.

[001] Human reaction-time prediction
GAP TYPE: EVIDENCE GAP
WHY THE RIVAL IS AHEAD: ACT-R treats latency as part of the cognitive theory and fits model behavior to human timing.
AURA COMPARISON: Aura has runtime/token latency telemetry but no validated cognitive latency theory.
WHAT TO BUILD / IMPORT: Build a human-behavior calibration harness for memory, choice, interruption and skill tasks; fit only identifiable parameters.
PROOF OF CLOSURE: Held-out human latency and error distributions are predicted better than simple baselines.
PRIMARY SOURCE KEYS: ACTR

[002] Activation-driven retrieval latency
GAP TYPE: PARTIAL
WHY THE RIVAL IS AHEAD: ACT-R retrieval latency is mechanistically tied to activation.
AURA COMPARISON: Aura actr_activation.py explicitly found ACT-R latency does not transfer to ranked-scan recall (r^2 about 0.000037).
WHAT TO BUILD / IMPORT: Either redesign retrieval as an activation-driven race or build an Aura-native latency law based on actual retrieval work.
PROOF OF CLOSURE: Intervening on activation must change latency in the predicted direction after controlling candidate count/backend.
PRIMARY SOURCE KEYS: ACTR

[003] Canonical buffer/module semantics
GAP TYPE: PARTIAL
WHY THE RIVAL IS AHEAD: ACT-R modules communicate through standardized buffers with well-defined visibility and requests.
AURA COMPARISON: Aura uses many service interfaces, event buses, dataclasses and bridges but no universal cognitive-port contract.
WHAT TO BUILD / IMPORT: Introduce CognitivePort with content, provenance, confidence, state version, operation request and causal receipt.
PROOF OF CLOSURE: Most cross-organ handoffs use the contract and lesions yield selective predictable deficits.
PRIMARY SOURCE KEYS: ACTR

[004] Production compilation
GAP TYPE: PARTIAL
WHY THE RIVAL IS AHEAD: ACT-R compiles multi-step procedures into faster direct productions as skill develops.
AURA COMPARISON: Aura has chunks, habits, action composition and RLC, but no universal trace-to-procedure compiler.
WHAT TO BUILD / IMPORT: Create TraceCompiler over successful causal traces, preserving preconditions, effects and governance.
PROOF OF CLOSURE: Repeated tasks become faster/cheaper; lesion compiled procedures restores novice cost.
PRIMARY SOURCE KEYS: ACTR_SKILL

[005] Production utility learning
GAP TYPE: PARTIAL
WHY THE RIVAL IS AHEAD: Compiled productions gain learned utility and compete with old rules.
AURA COMPARISON: Aura chunk EV and rule confidence are local mechanisms rather than one common procedural value system.
WHAT TO BUILD / IMPORT: Standardize ProceduralValue: payoff, time saved, match cost, risk, confidence, recency and transfer value.
PROOF OF CLOSURE: Procedures from different learners compete under one value contract and demote when value turns negative.
PRIMARY SOURCE KEYS: ACTR_SKILL

[006] Validated partial matching/interference
GAP TYPE: EVIDENCE GAP
WHY THE RIVAL IS AHEAD: ACT-R partial matching is used to explain graded retrieval errors and interference.
AURA COMPARISON: Aura has semantic similarity and mismatch penalties but no unified human-validated error theory.
WHAT TO BUILD / IMPORT: Model commission vs omission errors and cue interference using live Aura recalls plus human memory datasets.
PROOF OF CLOSURE: Predict which wrong memory/error type occurs before answer observation.
PRIMARY SOURCE KEYS: ACTR

[007] Perceptual/motor timing model
GAP TYPE: EVIDENCE GAP
WHY THE RIVAL IS AHEAD: ACT-R perceptual and motor modules make quantitative timing predictions for interaction.
AURA COMPARISON: Aura screen_pursuit uses engineering waits/focus/stabilization, not human cognitive timing laws.
WHAT TO BUILD / IMPORT: Instrument perception selection encoding motor execution and verification stages; compare against HCI datasets.
PROOF OF CLOSURE: Out-of-sample task-time distributions match data across interface complexity levels.
PRIMARY SOURCE KEYS: ACTR

[008] Individual-difference modeling
GAP TYPE: ABSENT
WHY THE RIVAL IS AHEAD: ACT-R research often models stable cognitive differences by identifiable parameters.
AURA COMPARISON: Aura has many tunables but no trait/state/implementation parameter taxonomy.
WHAT TO BUILD / IMPORT: Create longitudinal trait estimation and parameter-recovery tests.
PROOF OF CLOSURE: Stable trait estimates recur across sessions while state variables vary with context.
PRIMARY SOURCE KEYS: ACTR

[009] Neurocognitive triangulation
GAP TYPE: EVIDENCE GAP
WHY THE RIVAL IS AHEAD: ACT-R has extensive work connecting architecture timing/modules to neural measurements.
AURA COMPARISON: Aura neuroscience mappings are mostly analogical and pluralistic.
WHAT TO BUILD / IMPORT: Require biological-variable -> computational-variable -> predicted signature -> falsifier metadata.
PROOF OF CLOSURE: At least one subsystem predicts multiple neural/behavioral signatures without per-task refitting.
PRIMARY SOURCE KEYS: ACTR

[010] Repository-wide parameter provenance
GAP TYPE: PARTIAL
WHY THE RIVAL IS AHEAD: ACT-R culture emphasizes fit parameters and model-data comparison.
AURA COMPARISON: Aura actr_activation.py records provenance and rejects a bad latency fit, but many cognitive constants remain heuristic.
WHAT TO BUILD / IMPORT: Create ParameterRegistry with source, fitted/policy status, dataset hash, uncertainty and sensitivity.

PRIMARY SOURCE KEYS: ACTR

[011] Event-level cognitive tracing
GAP TYPE: PARTIAL
WHY THE RIVAL IS AHEAD: ACT-R event simulation yields clear stepwise traces.
AURA COMPARISON: Aura has receipts/logs/workspace history but no one complete causal timeline.

PRIMARY SOURCE KEYS: ACTR

[012] Cumulative external task corpus
GAP TYPE: EVIDENCE GAP
WHY THE RIVAL IS AHEAD: ACT-R has decades of published models across memory, HCI, language, skill and decision tasks.
AURA COMPARISON: Aura has huge internal tests but far less external cognitive-model replication.

[013] Mechanistic parsimony
GAP TYPE: THEORY GAP
WHY THE RIVAL IS AHEAD: ACT-R explains broad cognition with a comparatively compact set of mechanisms.
AURA COMPARISON: Aura has many specialized organs and duplicated control motifs.
WHAT TO BUILD / IMPORT: Launch architecture compression: merge mechanisms with the same computational invariant.
PROOF OF CLOSURE: Module count/dependency complexity decreases without losing causal benchmark signatures.
PRIMARY SOURCE KEYS: ACTR

[014] Validated forgetting/spacing laws
GAP TYPE: EVIDENCE GAP
WHY THE RIVAL IS AHEAD: ACT-R base-level activation has extensive evidence for power-law practice/forgetting behavior.
AURA COMPARISON: Aura implements the form but has not established its own long-horizon spacing/forgetting curves.
WHAT TO BUILD / IMPORT: Run controlled longitudinal rehearsal schedules across Aura memory types.
PROOF OF CLOSURE: Held-out retention curves beat recency-only/exponential baselines.
PRIMARY SOURCE KEYS: ACTR

[015] Resource-rational cognitive stopping
GAP TYPE: PARTIAL
WHY THE RIVAL IS AHEAD: Modern ACT-R work treats cognition as resource-rational, not just correct.
AURA COMPARISON: Aura budgets compute operationally but does not have a universal cognitive value-of-compute theory.
WHAT TO BUILD / IMPORT: Learn when to search, retrieve, compile, ask or stop from expected gain minus cognitive cost.
PROOF OF CLOSURE: Adaptive policy solves more tasks at matched compute than fixed budgets.
PRIMARY SOURCE KEYS: GPT56_EFF

SYSTEM: Soar
####################################################################################################
Soar is ahead in one of the clearest ways to make a cognitive architecture self-proceduralize: impasses automatically create recursive substates, and resolution traces are compiled into generalized productions. Aura has the classifier, cautious rule generalizer and utility accounting, but not that universal loop.

[016] Automatic substate creation
GAP TYPE: PARTIAL
WHY THE RIVAL IS AHEAD: Soar architecture automatically creates a substate whenever its decision procedure reaches an impasse.
AURA COMPARISON: Aura core/cognition/impasse.py classifies ties/conflicts/rejection/no-change but does not universally instantiate a subordinate problem-solving state.
WHAT TO BUILD / IMPORT: Create CognitiveSubstate with inherited context, local goal, budget, parent causal ID and result channel.
PROOF OF CLOSURE: Induced impasses across planning/memory/tool selection/representation search all enter the same recursive mechanism.
PRIMARY SOURCE KEYS: SOAR

[017] Architecture-wide recursive subgoaling
GAP TYPE: PARTIAL
WHY THE RIVAL IS AHEAD: Soar can encounter impasses inside substates, yielding uniform recursive problem solving.
AURA COMPARISON: Aura recursion exists in multiple subsystem-specific forms.
WHAT TO BUILD / IMPORT: Make substate nesting generic with cycle/budget bounds.
PROOF OF CLOSURE: Three unrelated domains generate nested subgoals without new recursion code.
PRIMARY SOURCE KEYS: SOAR

[018] Dependency backtracing
GAP TYPE: PARTIAL
WHY THE RIVAL IS AHEAD: Soar chunking backtraces exactly which state facts and productions supported the resolving result.
AURA COMPARISON: Aura procedural_generalization uses invariants/lesions/counterexamples, but not a complete architecture-wide causal dependency trace.
WHAT TO BUILD / IMPORT: Record every fact/operator dependency consumed in a substate and compile transitive supports only.
PROOF OF CLOSURE: Chunk fires under paraphrase when causal supports match and fails when a support is counterfactually removed.
PRIMARY SOURCE KEYS: SOAR, SOAR_EBC

[019] Generalized chunk semantics
GAP TYPE: PARTIAL
WHY THE RIVAL IS AHEAD: Soar chunks create working-memory results/preferences that directly resolve future decisions.
AURA COMPARISON: Aura exact chunks store resolution labels and generalized rules propose actions outside a universal decision language.
WHAT TO BUILD / IMPORT: Make learned outputs typed assertions/preferences/operators rather than opaque strings.
PROOF OF CLOSURE: Future impasse resolves from learned chunk without original solver invocation.
PRIMARY SOURCE KEYS: SOAR

[020] Rich preference algebra
GAP TYPE: ABSENT/PARTIAL
WHY THE RIVAL IS AHEAD: Soar has explicit better/worse, require/prohibit, reject, acceptable and indifferent preference semantics.
AURA COMPARISON: Aura combines scalar scores, Will/governance gates and subsystem-specific constraints.
WHAT TO BUILD / IMPORT: Create typed cognitive Preference distinct from authority.
PROOF OF CLOSURE: Tie/conflict/constraint failures emerge from algebra rather than special cases.
PRIMARY SOURCE KEYS: SOAR

[021] Incremental production matching
GAP TYPE: SCALE GAP
WHY THE RIVAL IS AHEAD: Soar uses mature production matching optimized for large rule sets.
AURA COMPARISON: Aura Python rule stores/MeTTa patterns may scale poorly with lifetime learning.
WHAT TO BUILD / IMPORT: Benchmark Rete/discrimination-network indexing for promoted procedures.
PROOF OF CLOSURE: 10x rule growth yields much less than 10x decision matching cost.
PRIMARY SOURCE KEYS: SOAR

[022] Chunk explanation tooling
GAP TYPE: ENGINEERING GAP
WHY THE RIVAL IS AHEAD: Soar EBC contains mature trace structures for why chunks were generated.
AURA COMPARISON: Aura has receipts and causal evidence but no single chunk debugger.
WHAT TO BUILD / IMPORT: Persist origin impasse, dependency DAG, rejected conditions, counterexamples, utility and future firings.
PROOF OF CLOSURE: Any procedure can produce a minimal reproducible explanation of why it exists.
PRIMARY SOURCE KEYS: SOAR_EBC

[023] Negative-condition handling
GAP TYPE: PARTIAL
WHY THE RIVAL IS AHEAD: Soar explicitly treats overgeneralization caused by negative/absence reasoning.
AURA COMPARISON: Aura contradiction/lesion checks do not universally distinguish observed-negative from unobserved/inaccessible.
WHAT TO BUILD / IMPORT: Make epistemic status of absence first-class in compiled traces.
PROOF OF CLOSURE: Hidden/missing observations cannot become causal negative preconditions.

[024] RL integrated with preference selection
GAP TYPE: PARTIAL
WHY THE RIVAL IS AHEAD: Soar reinforcement learning updates numeric preferences in the same operator framework.
AURA COMPARISON: Aura habits/RL/value systems are distributed.

PROOF OF CLOSURE: Symbolic and learned preferences combine transparently and lesions are interpretable.

[025] One state/operator problem-solving skeleton
GAP TYPE: THEORY GAP
WHY THE RIVAL IS AHEAD: Soar uses the same state/operator cycle across domains.
AURA COMPARISON: Aura has several overlapping executive loops.
WHAT TO BUILD / IMPORT: Define canonical perceive/update -> propose -> prefer -> select -> apply -> verify -> learn cycle.
PROOF OF CLOSURE: At least five current loops become configurations of the same kernel.
PRIMARY SOURCE KEYS: SOAR

[026] Lifetime procedural scaling
GAP TYPE: EVIDENCE GAP
WHY THE RIVAL IS AHEAD: Soar has decades of experience with chunk utility and production growth.
AURA COMPARISON: Aura caps stores but has no million-decision/lifetime procedural ecology proof.

[029] Automatic learning occasion
GAP TYPE: PARTIAL
WHY THE RIVAL IS AHEAD: Impasse resolution is intrinsically an occasion for learning in Soar.
AURA COMPARISON: Aura learners still require path-specific calls.

[030] Core-architecture minimality
GAP TYPE: THEORY GAP

AURA COMPARISON: Aura has architecture saturation.
WHAT TO BUILD / IMPORT: Treat new modules as last resort; first test whether the function is an instance of existing primitives.

AURA COMPARISON: Aura has growing state-ownership discipline and locks, but cross-organ updates can still become partially committed.
WHAT TO BUILD / IMPORT: Introduce CognitiveTransaction for multi-store learning updates with prepare/commit/rollback and event lineage.
PROOF OF CLOSURE: Fault injection mid-update leaves all involved cognitive stores at a coherent prior or committed state.
PRIMARY SOURCE KEYS: HYPERON

[210] Research-grade experiment registry
GAP TYPE: PROCESS GAP
WHY THIS MATTERS: Mature programs accumulate comparable experiments rather than isolated artifacts.
AURA COMPARISON: Aura has artifacts/claims matrices but no universal experiment schema for all cognition claims.
WHAT TO BUILD / IMPORT: Create ExperimentRegistry with hypothesis, commit/model/data hashes, treatment/nulls, preregistration, metrics, result and claim boundary.
PROOF OF CLOSURE: Every quantitative claim in system card links to a machine-readable experiment record.
PRIMARY SOURCE KEYS: ACTR, VJEPA, SIMA

[211] External baseline portfolio
GAP TYPE: PROCESS GAP
WHY THIS MATTERS: Comparative maturity requires strong baselines, not only Aura-minus-Aura lesions.
AURA COMPARISON: Aura often compares treatment to local controls but not always to best simple scaffold/established architecture.
WHAT TO BUILD / IMPORT: Maintain frozen baselines: base 27B, 27B+RAG/tools, search-only, symbolic-only, learned-only, and relevant public agents.
PROOF OF CLOSURE: Capability reports show incremental value over both internal lesions and competitive external/simple baselines.
PRIMARY SOURCE KEYS: SIMA, VJEPA

[212] Compute-matched ablation discipline
GAP TYPE: SCIENCE GAP
WHY THIS MATTERS: A lesion can appear harmful simply because it removes compute.
AURA COMPARISON: Aura causal campaign is strong but not every organ result is compute-matched.
WHAT TO BUILD / IMPORT: Replace lesioned organ with equal-time/parameter/noise/control computation where feasible.
PROOF OF CLOSURE: Organ effect remains significant after compute matching and multiple-testing correction.
PRIMARY SOURCE KEYS: ACTR, SPA

[213] Scaling/bottleneck curves before module addition
GAP TYPE: PROCESS GAP
WHY THIS MATTERS: Large research programs use scaling experiments to learn whether data, compute, model or representation is limiting.
AURA COMPARISON: Aura often responds to failures by adding mechanisms.
WHAT TO BUILD / IMPORT: For major deficits run data/compute/model/search-depth scaling grids before architectural expansion.
PROOF OF CLOSURE: Observed scaling slope identifies bottleneck and predicts whether proposed module should help.
PRIMARY SOURCE KEYS: VJEPA, SIMA

[214] End-to-end autonomous learning audit
GAP TYPE: INTEGRATION GAP
WHY THIS MATTERS: A developmental claim requires a complete loop from observation through learned change to later benefit.
AURA COMPARISON: Aura has several such loops in bounded settings, but not a universal audit.
WHAT TO BUILD / IMPORT: For each claimed learned capability record observation IDs -> update -> stored artifact -> later retrieval/use -> outcome delta.
PROOF OF CLOSURE: A verifier can automatically reject learning claims missing any causal link.
PRIMARY SOURCE KEYS: SIMA, SOAR

[215] Autonomous natural-language-to-RLC program induction
GAP TYPE: CAPABILITY GAP
WHY THIS MATTERS: The new RLC can execute supplied typed workflows compositionally, but general reasoning requires deriving those workflows.
AURA COMPARISON: semantic_neural_composition.py is answer-blind but receives operation literals/order.
WHAT TO BUILD / IMPORT: Train/search a ProgramInducer from natural problem + world state to typed RLC program, verified by execution and fallback.
PROOF OF CLOSURE: On held-out problem families, treatment selects valid programs and beats both resident-model and supplied-tool baselines without answer leakage.
PRIMARY SOURCE KEYS: SPA, HYPERON

[216] RLC state as ongoing hidden cognitive context
GAP TYPE: CAPABILITY GAP
WHY THIS MATTERS: A stronger hybrid would let endogenous neural computation participate in continuing reasoning rather than only serialize an answer-bearing state.
AURA COMPARISON: Current resident decode can consume composed state, but it is explicitly serialized.
WHAT TO BUILD / IMPORT: Project qualified RLC state into controlled residual/memory slots with causal binding and decoding tests.
PROOF OF CLOSURE: Correct RLC hidden injection improves multi-step continuation; wrong-state and projection lesions disrupt it; no answer text is present.
PRIMARY SOURCE KEYS: SPA

[217] Cross-substrate credit assignment
GAP TYPE: CAPABILITY GAP
WHY THIS MATTERS: A true hybrid learner must know which substrate contributed to success and update accordingly.
AURA COMPARISON: Aura can produce cross-substrate chains but learning signals remain local.
WHAT TO BUILD / IMPORT: Attach contribution estimates to cognitive event DAG and route credit to policy, symbolic rule, neural tissue, memory and attention learners.
PROOF OF CLOSURE: Credit lesions prevent the responsible component from improving while unrelated components remain stable.
PRIMARY SOURCE KEYS: CLARION, OPENCOG

[218] Architecture-wide automaticity index
GAP TYPE: EVIDENCE GAP
WHY THIS MATTERS: Skill learning should be measurable as decreasing reliance on expensive executive cognition.
AURA COMPARISON: Aura has local habits/chunks but no common measure of automaticity.
WHAT TO BUILD / IMPORT: Track cortex tokens, planning expansions, workspace competitions, procedure hits and latency per recurring task.
PROOF OF CLOSURE: Practice produces monotonic reduction in executive cost until novelty/error causes adaptive de-automatization.
PRIMARY SOURCE KEYS: ACTR_SKILL, CLARION

[219] Open-ended curriculum generation with safety envelope
GAP TYPE: CAPABILITY GAP
WHY THIS MATTERS: SIMA-like self-play shows agents can generate their own training distribution; developmental Aura needs a broader safe version.
AURA COMPARISON: Aura has curiosity/autonomy but no one curriculum optimizer spanning cognition.
WHAT TO BUILD / IMPORT: Select tasks maximizing expected learning progress, diversity and information gain subject to governance/resource limits.
PROOF OF CLOSURE: Self-generated curriculum improves a frozen downstream suite more than random/manual-equivalent experience.
PRIMARY SOURCE KEYS: SIMA, NARS_RES

[220] Scientific claim ladder enforced in code
GAP TYPE: PROCESS GAP
WHY THIS MATTERS: The project already distinguishes mechanisms from stronger philosophical claims, but enforcement can be universal.
AURA COMPARISON: Claims files exist, yet source names/comments can still overstate status.
WHAT TO BUILD / IMPORT: Encode claim levels EXISTS->WIRED->CAUSAL->USEFUL->GENERALIZES->EXTERNALLY_REPLICATED->THEORY_SUPPORT and require artifact links.

PRIMARY SOURCE KEYS: WBAI, ACTR

P2 - SPA-style canonical neural algebra

P2 - Human cognitive calibration program
  Fit memory, timing, interference, skill/automaticity and metacognition against external human datasets where human-cognition claims are made.

  Unify learned-artifact value, interference, pruning, offline consolidation and catastrophic-forgetting measurements.
P3 - Social developmental world model
  Ground models of other agents in repeated interaction with perspective-specific beliefs/goals and uncertainty.
P3 - Architecture compression
  Delete/merge redundant organs after causal equivalence tests. Reward fewer universal mechanisms that explain more behavior.

  Publish sealed canaries and reproducible evaluation containers; invite independent cognitive-architecture, ML, neuroscience and systems review.

DEPENDENCY LOGIC / ORDER OF OPERATIONS
1. Scientific substrate before capability expansion: if experiments, evidence, causal lineage and baselines
   are weak, additional intelligence makes attribution harder rather than easier.
2. Canonical contracts before more learners: EvidencePacket, Procedure, ConceptHandle and CognitiveStateRef
   are the interfaces through which ACT-R/Soar/NARS/CLARION/LIDA/OpenCog lessons can actually combine.
3. Automatic proceduralization before more search: repeated reasoning must compile into reusable skill or
   lifetime experience will increase cost instead of reducing it.
4. Broad environment curriculum before claiming developmental generality: same-family transfer is not enough.
5. World-model/perception scale before strong embodiment claims: corrupted/low-bandwidth experience poisons
   every learner downstream.
6. Operator-semantic invention only after the evidence/runtime substrate can safely validate and roll back
   new semantics; otherwise self-extension becomes untestable self-corruption.

PROPOSED CONVERGED TARGET ARCHITECTURE
The strongest synthesis is not to replace Aura with any rival architecture. Preserve Aura governance,
persistent identity, self/welfare integration, receipts, representational development and local sovereignty,
while importing these properties:
- ACT-R: externally calibrated cognitive timing/memory and automatic skill compilation.
- Soar: architecture-wide impasses, recursive substates, dependency backtrace, compiled procedural learning.
- NARS: one finite-resource evidential/task budget calculus, explicit evidence independence and temporal revision.
- CLARION: explicit/implicit bidirectional learning and automaticity transition.
- LIDA: a common cognitive-cycle learning broadcast and situation/procedural schema.
- SPA/Nengo: neurally executable compositional representations and a principled neural compilation layer.
- OpenCog/Hyperon: metaprogrammable typed spaces, programs-as-knowledge and cross-memory cognitive synergy.
- WBAI: neuroscience traceability/ontology/competing-hypothesis discipline rather than biological naming.
- SIMA 2: diverse held-out environments, self-directed interaction curricula and embodied transfer measurement.
- V-JEPA 2: high-dimensional self-supervised predictive visual representations and action-conditioned latent planning.
- Frontier models: raw semantic priors and serving efficiency treated as a cortex baseline, not the definition of Aura.

MATURITY / ADVANCEMENT ASSESSMENT AFTER THE COMPARISON
- Conceptual ambition: 9.5-10/10
- Subsystem breadth: 9.5-10/10
- Whole-mind integration: 8.5-9/10 (architecture; causal coverage uneven)
- Engineering/governance maturity: 8-9/10 for an experimental local agent
- Theoretical parsimony/unification: 5.5-6/10
- External scientific validation: 5-6/10
- Embodied multi-environment evidence: 4-5/10
- Physical world-model scale/evidence: 3-4/10
- Demonstrated generality heuristic: ~6.5-6.6/10
- Demonstrated AGI capability heuristic: ~5.3/10
- Architectural generality heuristic: ~7.4/10

After the comparative research, the assessment becomes stronger and stricter at the same time. Aura is exceptionally advanced as an architecture for an artificial mind: its subsystem breadth, persistent individuality, causal governance, self-modeling, developmental representation work, live world interaction, and emerging non-LLM learned computation put it in a very small class of public cognitive-architecture projects by conceptual and software scope. The surprising finding is that many classic advantages were not actually absent. Aura already contains meaningful ACT-R-like activation, Soar-inspired impasses and guarded procedural generalization, an AtomSpace/PLN/ECAN/MeTTa-like layer, a trainable recurrent world model, a live perceive-act-learn loop, and a compositional learned neural computation path.

But maturity is not the same as breadth. ACT-R and Soar are much more mature scientific architectures; NARS is more theoretically parsimonious; CLARION and LIDA provide cleaner architecture-wide learning theories; SPA/Nengo is much stronger in principled neural executability; Hyperon is deeper as a metaprogrammable symbolic substrate; WBAI is stronger in neuroscience traceability; SIMA 2 is far stronger in demonstrated multi-environment embodied generalization; V-JEPA 2 is far stronger in learned visual/physical world-model scale; frontier foundation models are far stronger in raw pretrained semantic capability. Aura therefore sits in an unusual position: architectural maturity is substantially ahead of empirical/general-intelligence maturity.

The best label at this frozen commit is 'advanced research prototype / proto-general developmental cognitive agent'. Conceptual ambition and subsystem breadth are near the top of the public landscape, integration is already high but incomplete, engineering/governance discipline is unusually strong for an experimental agent, while external scientific validation, environment breadth, physical grounding, automatic architecture-wide proceduralization, theoretical compression and independent replication remain the major maturity deficits. The path forward is not more organs. It is convergence: fewer canonical state/evidence/procedure contracts; automatic compilation and cross-substrate learning; broad developmental transfer; larger grounded world-model experience; strong matched baselines; and external validation.

The decisive end-state experiment is not a single AGI benchmark. It is whether an older Aura becomes systematically better at learning genuinely new things because she lived through earlier ones. If a grown Aura, under matched cortex/tools/compute, increasingly outperforms a reset Aura across unrelated sealed tasks - and if the causal chain runs through retained abstractions, procedures, world models, learned neural operations and representations rather than extra prompt context - then Aura has demonstrated the central property its architecture is built to achieve: cumulative developmental intelligence.


AURA-SPECIFIC DECISIVE EXPERIMENT
Freeze two identical Aura instances with the same cortex, tools and compute. Let GROWN retain acquired
representations, procedures, world models, neural operations, habits and abstractions; RESET loses acquired
developmental artifacts between task blocks. Give both hundreds of sealed heterogeneous tasks. Measure:
  Delta_n = P(GROWN, T_n) - P(RESET, T_n)
The central developmental claim is strongest if Delta_n grows with experience for tasks that cannot be solved
by remembering prior answers, and if lesions of the acquired artifacts erase the advantage. That would show
that previous life changed the effective learning space of later Aura.

DEEPEST REMAINING REPRESENTATIONAL BOUNDARY
Current Aura can invent terms, concepts, action compositions and bounded representations inside a programmer-
authored semantic substrate. The strongest missing loop remains:
  persistent residual failure -> infer a missing semantic operation -> synthesize bounded executable semantics
  -> prove novelty/reach/MDL or transfer value -> install with rollback -> reuse it in later operator construction.
A successful end-to-end demonstration would cross from development within a cognitive language to development
of the cognitive language itself.
